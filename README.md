# PRISONER.DILEMMA.BAS

A retro 1980s-PC-styled game of trust, betrayal, and game theory — the Iterated
Prisoner's Dilemma, playable in your browser.

Inspired by Robert Axelrod's famous 1980 computer tournaments and Veritasium's
video ["This game theory problem will change the way you see the world"](https://www.youtube.com/watch?v=mScpHTIi-kM).

## Play

Open `index.html` in any browser — or play the hosted version via GitHub Pages.

- **Quick Match** — face a mystery strategy; identify it by its behavior, then see
  its museum plaque at the reveal
- **Tournament** — recreate the 1980 Axelrod tournament: you vs. all 15 historical
  entrants, with a line-printer standings sheet at the end
- **Head to Head** — 2 players, one machine, secret simultaneous keys
- **Strategy Lab** — design your own strategy and write it to a floppy disk
- **Batch Job** — pit your disk against the field
- **C:\ Prompt** — for advanced users. Type `HELP`. Some commands are not listed.

23 historical strategies with correct names and attributions, drawn from the
[Axelrod-Python](https://axelrod.readthedocs.io) research library's documentation.

Built with plain HTML/CSS/JavaScript. No frameworks, no build step, no server.
